# New Year Canvas 🎉

Este proyecto es una pequeña aplicación web de entretenimiento, creada con **HTML5 Canvas API**, **HTML** y **CSS**.

Su propósito es meramente ilustrativo: mostrar un **efecto visual animado** para celebrar el Año Nuevo de forma divertida.

## Cómo funciona

- La página muestra un lienzo `<canvas>` que renderiza efectos visuales (partículas, fuegos artificiales, textos animados, etc.).
- Está hecha solo con tecnologías web básicas, sin dependencias externas.
- Es ideal como ejercicio de aprendizaje de animación con Canvas API.

## Estructura

- `index.html`: estructura principal de la página y el elemento `<canvas>`.
- `style.css`: estilos básicos para centrar y decorar el lienzo.
- `script.js`: El eje de control de canvas.
- `README.md`: esta documentación.
